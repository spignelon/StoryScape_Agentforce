## Problem Statement
- Nowadays students face problem due to `low attention span` which is less than a gold fish.
    - Gold fish attention span: `9 sec`
    - Humans attention span: `8 sec`

- Also, It is `very hard to spread awareness` about topics which are considered
`"taboo"` in our society such as `periods`, `superstations`, `sex education`, etc.

- As per studies conducted in `US by NCBI`, suggested that approx. `65%` of the
population are `visual learners`, So learning from textual content leads to
    - Difficulty in Conceptualization
    - Reduced Retention
    - Limited Engagement
    - Difficulty in Problem-Solving
    - Limited Creativity and Expression
    - Increased Cognitive Load

## Our Solution
- Our idea is to build an Agentforce-powered platform, which will `convert boring textual content or taboo topics` to visually appealing `comics/manga`.

- User can `specify plot` & `characters` of the storyline `or just enter a topic` and it will generate a comic book as per their `comic style` i.e. `Marvel`, `DC`, `Disney Princess`, `Anime` etc.

- Our platform utilizes Salesforce Agentforce for intelligent text processing and conversation generation, coupled with `Stable Diffusion` for `text-to-image transformations`.

- We optimize the pipeline to `generate a comic under 30-50 secs` using `Multithreading` & `Caching database (Redis)`.

## Features Offered
- [X] Generate in your favourite comic style i.e. Marvel, DC, etc
- [X] Ability to set custom characters and story plot
- [X] Generate Shareable comic link or share comic pdf
- [X] Enhances user experience with realistic animations simulating page turning
and book opening/closing, creating an immersive digital reading
environment.
- [X] Ability to create vernacular(Hindi/English/Tamil/etc) comics

# StoryScape : Two Core Components

1. [Comics-Dialogue-Generator 📝](#Comics-Dialogue-Generator)
2. [Comics-Scenes-Generator 💬🤖](#Comics-Scenes-Generator)

<a name="Comics-Dialogue-Generator"></a>
## Comics-Dialogue-Generator 📝

- This component leverages Salesforce Agentforce API for generating engaging comic dialogues based on textual prompts. 
- For creating high quality comic scene images, we generate dynamic image prompts that specify minute details about the comic scenes. These prompts are created using Agentforce by supplying comic scene dialogue.
- The Agentforce agent processes the input prompt and produces comic dialogues in a structured format, ready for visualization.
- The agent is specifically designed to understand storytelling elements and generate conversational content that matches the desired comic style (Marvel, DC, Disney, etc.)


<a name="Comics-Scenes-Generator"></a>
## Comics-Scenes-Generator 👤🚀

- This component implements an image generation model using Stable Diffusion API.
- The model is designed to generate visually appealing comic scenes based on the dialogues created by our Agentforce agent.
- We've optimized the integration between Agentforce and Stable Diffusion to ensure the visual elements perfectly match the narrative context.

# Flow Diagram 🔄📊

1. User will login with **google auth** & will get redirected to main dashboard.
2. User will enter **Topic**(required), **Comic style**(optional), **Story plot**(optional) & **Characters** (optional).
3. After hitting enter, web application will run a **celery worker for generating a comic**
4. User will be **redirected to waiting page** where he will **get info** about the **progress**.
5. Once comic is generated, user will be **redirected to comic viewer**
6. Comic viewer will have **options** to **download** the **comic** in **pdf format** or **share** the **web comic viewer link**.

# Technologies Used 🛠️    

1. **Salesforce Agentforce:** The core AI agent technology that powers our dialogue generation system. Agentforce enables our application to generate contextually relevant, engaging comic dialogues based on user inputs.

2. **Backend - Flask:** Our application's backend was constructed using Flask, a versatile Python web framework. Flask facilitated the development of RESTful APIs, user authentication, data processing, and integration with Agentforce.

3. **Machine Learning Models:** Our app integrates Agentforce with Stable Diffusion for transforming textual content into visual representations.
    - **Text Generation** - Salesforce Agentforce API
    - **Image Generation** - Stable Diffusion API

4. **Other Technologies:** In addition to Agentforce, Flask, and Stable Diffusion, our application utilizes:
    - **Celery:** Comic Generation usually takes more than 30 seconds, which can lead to 502 Gateway errors, so we've implemented Celery Worker to execute the comic generation pipeline on the server.
    - **Redis:** Used as a Broker & Caching Database to boost performance & also used in developing Flask API for showing comic progress on the frontend (Loading Page)

# How We Built It 🛠️👷‍♂️

- User inputs a topic with story plot
- The `Input Text` is then given to the `Salesforce Agentforce API`
- Agentforce processes the input and generates creative comic dialogues with proper character development
- `Raw Comic Dialogues Text` is then parsed using `Post Processing functions` which `returns` the `result` in `JSON Format`
- `For Generating Comic Poster`, a Dynamic Image Generation prompt is generated using Agentforce by supplying comic topic
- `Dynamic Image prompt` is then `given to Image Generation Model` (Stable Diffusion API)
- Similarly for generating comic scenes, a dynamic image prompt is generated using Agentforce by supplying Comic Scene Dialogue
- Then that dynamically generated prompt is used to generate Comic scenes using Stable Diffusion
- `Multithreading` is used for `parallel image & text generation`
- Once Comic Images are generated, we `write` the `text on top of image` using `OpenCV` in `comic font`
- Then Finally we merge the images using custom `Image List to PDF generator` code
- `Celery worker` runs the above task & updates the `Redis db` for `saving` the `progress`
- We have created a `Flask-Restful API` which is connected to Redis for `fetching the progress`
- `Loading page` calls this API `every 2 seconds` and shows the `progress` on the page
- Once the `API status is completed`, the page automatically `loads` the `Comic viewer`
- `Comic viewer` has the functionality to either `read the comic on website itself` using `realistic page turn animation` & providing immersive comic reading experience
- Also at the end of comic page, there is an option to `download` the `comic in PDF format`

## Installation
```
# Install Redis
sudo apt install redis-server nginx python3-pip -y
sudo systemctl start redis-server
sudo systemctl enable redis-server
sudo service redis-server status 

# Install VirtualEnv
pip3 install virtualenv

# Clone Project
git clone https://github.com/spignelon/StoryScape_Agentforce.git

# Navigate to folder
cd StoryScape

# Create Virtual Environment
virtualenv venv

# Activate Virtual Env.
source venv/bin/activate

# Install Requirements
pip3 install -r requirements.txt

# Create .env file with your Agentforce credentials
echo "AGENTFORCE_API_BASE=your_base_url
MY_DOMAIN_URL=your_domain_url
AGENT_ID=your_agent_id
ACCESS_TOKEN=your_access_token" > .env
```
